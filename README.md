# hologen-network.github.io
Hologen Training Network website

## Content editing

The public site is still hosted as a static GitHub Pages site. Blog posts are generated by Jekyll from Markdown files in `_posts`, and uploaded blog media is stored in `assets/uploads`.

The repository includes a Pages CMS configuration in `.pages.yml`. After installing the Pages CMS GitHub App for `hologen-network/hologen-network.github.io`, editors can sign in at `https://app.pagescms.org/` or use `/admin/` on the public site as an entry point.

Blog posts are exposed as structured editor forms. Existing Mobirise pages are exposed as code-editable HTML files for trusted admins; converting those pages to structured forms should be a separate migration step if non-technical editors need to update them frequently.

Give editing rights only to the intended users through the GitHub repository, an organization team, or Pages CMS collaborators.
